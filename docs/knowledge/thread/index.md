# Thread

The main conversation thread: how a turn is rendered, and the plan that
rebuilds that rendering as a science-based, simplified reading surface.

Today a turn paints one bordered card per tool call with the full input JSON
and the full output JSON inside it, a second bordered card per sub-agent
dispatch with the same JSON nested one level deeper, and a stack of bordered
cards for every typed science part. The prose the Lead wrote is one item in
that stack. The redesign inverts it: prose is the turn, tool activity is a
quiet trace, and the science renders as flat figures in the reading flow.
